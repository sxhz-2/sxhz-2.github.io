🚀 部署指引（只需 3 步）

全程网页操作 · 零命令行 · 约 5 分钟上线

目标：把 index.html 变成能访问的网站 https://你的用户名.github.io/。
你的 index.html 是预构建单文件，无需构建，用最简单的方式即可上线。

1清空仓库 + 上传 3 个文件

📍 操作：浏览器打开你的仓库页面 → 删除里面所有旧文件（点每个文件右上角垃圾桶）→ 点 Add file → Upload files → 把本包的 index.html、guide.html、README.md 拖进去 → Commit changes。
✅ 成功标志：仓库里只剩这 3 个文件（+ 隐藏的 .nojekyll）
⚠️ 找不到删除按钮？可去 Settings → 最底部 Delete this repository 删库重建（同名）。

2开启 Pages（一次性）

📍 操作：仓库 → Settings → Pages（左侧菜单）→
  • Source 选 Deploy from a branch（⚠️ 不是 GitHub Actions）
  • Branch 选 main
  • 文件夹 选 /(root)
  → 点 Save。
✅ 成功标志：页面提示 "Your site is published at https://xxx.github.io/"
⚠️ 手机点不到？浏览器菜单 → "桌面版网站"，变电脑布局更好点。

3验证上线

📍 操作：等约 30 秒，浏览器打开 https://你的用户名.github.io/。
✅ 成功标志：显示「必修一·全部 · 剩余 409 / 已掌握 103」等统计 = 上线成功 🎉
⚠️ 若还是旧界面 → 地址栏重输一遍网址（硬刷新），或等 1-2 分钟再试。

★以后如何更新数据？

只改 index.html → 回到仓库 Upload files 覆盖同名文件 → 提交 → 约 30 秒自动上线。
全程不用命令行，和这次一模一样。
